# CRUD TODO App

A simple cross-platform TODO application built with **React Native** and **Expo**.
This project was created to showcase my **mobile development skills** — not my design abilities — so it’s purely functional with no fancy UI.

You can **create**, **view**, **edit**, and **delete** tasks. Notifications and additional features may come later, but for now, it’s all about the core logic and structure.
---

## Features

- Create new TODO items
- View your task list
- Edit existing tasks
- Delete tasks
- Runs on **Android**, **iOS**, and **Web** via Expo

---

## Tech Stack

- **React Native**
- **Expo**
- **JavaScript (ES6+)**

---

## Getting Started

To get the project running locally:

```bash
git clone https://github.com/lionsgrandson/CrudApp
cd CrudApp
npm install
```

Then start the app:

```bash
npm start
```

### Platform Commands

```bash
npm run android   # Run on Android
npm run ios       # Run on iOS
npm run web       # Run in web browser
npm run lint      # Run lint checks
npm run reset-project  # Reset project files
```
